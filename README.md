# 魔法海豚護法 (Patronus Dolphin)

這是一個以《哈利波特》神護州 (Expecto Patronum) 為靈感製作的煙霧狀藍銀色海豚護法網頁。

## 🌟 特點：
1. **方向修改**：海豚護法從**右下角游向左上角**。
2. **煙霧質感**：採用粒子系統與相加混合模式（Additive Blending），打造如真似幻的藍銀色流動煙霧與光粒效果。
3. **優雅擬真 2D 廓型**：包含海豚喙部、額隆、背鰭、胸鰭與雙尾鰭波浪形擺動。
4. **極簡一鍵部署**：包含 `package.json` 與 `server.js`，可直接上傳 GitHub 並免費部署至 Render。

## 🚀 部署教學 (GitHub + Render)

### 步驟 1：上傳至 GitHub
1. 解壓縮後將資料夾內的檔案推送到您的 GitHub 新建儲存庫 (Repository)。

### 步驟 2：部署至 Render
1. 登入 [Render.com](https://render.com/)。
2. 點擊 **New +** -> 選擇 **Web Service**。
3. 連接您的 GitHub 儲存庫。
4. Build Command 填寫：`npm install`
5. Start Command 填寫：`npm start`
6. 點擊 **Create Web Service** 即可完成上線！
