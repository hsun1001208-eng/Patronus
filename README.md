# Dolphin Patronus V8

Tap anywhere on the black screen.

The dolphin is drawn as a recognizable bottlenose-dolphin side profile with a translucent smoky Patronus treatment. Its tail, fins and body animate continuously while it travels.

Motion:
1. Enters from completely off-screen at the lower-right.
2. Smoothly follows one large oval circuit, keeping the dolphin inside the screen.
3. Continues naturally toward and off-screen at the upper-left.

Render:
- Build Command: leave blank
- Start Command: `npm start`
